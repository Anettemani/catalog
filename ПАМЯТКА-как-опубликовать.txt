Вариант 1 — GITHUB PAGES (рекомендую, бесплатно навсегда)
════════════════════════════════════════════════════════════

1. Зарегистрируйтесь на  https://github.com/signup
   (бесплатно, нужна только почта; интерфейс английский,
   но ниже — точный маршрут, что нажимать)

2. Создайте репозиторий:
   • Нажмите на «+» в правом верхнем углу -> «New repository»
   • В поле «Repository name» напишите:  catalog
   • Выберите «Public» (обязательно — иначе сайт не включится)
   • Нажмите зелёную кнопку «Create repository»

3. Загрузите файлы сайта:
   • На открывшейся странице нажмите «uploading an existing file»
     (ссылка прямо в центре)
   • Распакуйте ZIP у себя на компьютере, ОТКРОЙТЕ папку,
     выделите ВСЕ файлы и папки внутри (Ctrl+A) и
     ПЕРЕТАЩИТЕ их в окно браузера GitHub
     (важно: тащите содержимое папки, а не саму папку,
     чтобы index.html оказался «на верхнем уровне»)
   • Дождитесь окончания загрузки (~74 файла, 11 МБ)
   • Нажмите кнопку «Commit changes» (зелёная)

4. Включите сайт:
   • В меню сверху репозитория: «Settings» -> слева «Pages»
   • В разделе «Branch»: выберите  main  и папку  /(root),
     нажмите «Save»
   • Подождите 1–2 минуты, обновите страницу

5. Готово! Сайт будет доступен по адресу:
   https://ВАШ_ЛОГИН.github.io/catalog/
   (логин — тот, что вы выбрали при регистрации)

Как обновлять сайт потом:
   Откройте репозиторий -> «Add file» -> «Upload files» ->
   перетащите изменённые файлы -> «Commit changes».
   Через минуту сайт обновится сам.

Если GitHub вдруг медленно открывается у вашего провайдера —
попробуйте с телефона другого оператора или в другое время:
официально GitHub в России не заблокирован, но иногда
замедляется (ситуация на конец 2026 года).

Вариант 2 — NEOCITIES (проще всего, drag-and-drop)
════════════════════════════════════════════════════════════

1. Зарегистрируйтесь на  https://neocities.org  (кнопка
   «Sign up», бесплатно, нужна только почта)
2. В личном кабинете нажмите «Upload» / перетащите файлы
   прямо в окно — так же, как в GitHub: выделите всё
   содержимое распакованной папки и перетащите в браузер
3. Сайт сразу появится по адресу:
   https://ВАШ_ЛОГИН.neocities.org

Бесплатный тариф: 1 ГБ места (наш сайт — 11 МБ, хватит
с запасом), без рекламы. Имя сайта можно выбрать
при регистрации.

──────────────────────────────────────────────────────────────────
КАК ДОБАВИТЬ НОВЫЙ ЭСКИЗ В КАТАЛОГ
──────────────────────────────────────────────────────────────────

  1. Подготовьте картинку эскиза:
     • ОБЯЗАТЕЛЬНО нанесите водяной знак «@anette_mani»
       (диагональный, полупрозрачный — как на текущих картинках),
       иначе эскиз можно будет украсть в чистом виде;
     • уменьшите до ~1000–1100 px по большей стороне;
     • сохраните как JPG (качество 80–85);
     • назовите файл латиницей, например:  mynails027-a1b2c3.jpg
  2. Положите файл в папку  assets/img/wm/
  3. Откройте файл  assets/js/data.js  и в нужной коллекции
     допишите строку по образцу:

       {n:27,t:'MY NAILS #027 - Название',img:'mynails027-a1b2c3.jpg',ali:'https://aliexpress.ru/item/...ссылка...'},

     n ..... номер пластины (новинки — большие номера)
     t ..... название, как показывать в каталоге
     img ... имя файла картинки
     ali ... ссылка на товар AliExpress
  4. Если сайт на GitHub Pages: откройте репозиторий ->
     «Add file» -> «Upload files» -> перетащите изменённый
     файл data.js (и новую картинку) -> «Commit changes».
     Если на Neocities: зайдите в кабинет и загрузите
     изменённые файлы тем же способом.

──────────────────────────────────────────────────────────────────
ЧТО УЖЕ СДЕЛАНО ДЛЯ ЗАЩИТЫ ЭСКИЗОВ
──────────────────────────────────────────────────────────────────

  ✓ Водяной знак «@anette_mani» впечатан в сами файлы картинок —
    даже скриншот или сохранённый файл останется с вашей подписью
  ✓ Картинки подключены без прямых тегов <img> — «Сохранить как...»
    через браузер не работает
  ✓ Прозрачный «щит» поверх каждого эскиза
  ✓ Отключено контекстное меню (правый клик / долгое нажатие)
  ✓ Отключено перетаскивание и выделение картинок и текста
  ✓ Заблокированы Ctrl+S (сохранить), Ctrl+U (код), Ctrl+P (печать)
  ✓ Печать страницы выдаёт только надпись об авторских правах
  ✓ robots.txt запрещает Яндексу и Google индексировать папку
    с картинками (их не будет в поиске по картинкам)
  ✓ Имена файлов картинок содержат случайный код — адрес нельзя
    угадать и скачать всё подряд

Важно понимать: 100%-й защиты в интернете не бывает — экран телефона
можно сфотографировать. Но водяной знак гарантирует, что авторство
всё равно будет видно, а перечисленные меры отсекают все простые
способы копирования.
